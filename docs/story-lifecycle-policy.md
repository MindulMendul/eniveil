# 창작 작품 공개·삭제와 진행 중 플레이 정책

이 문서는 #181의 현재 동작과 운영 판단 기준을 정리한다. 작성 기능이 숨김 상태여도 기존 초안·공개 작품과 실행 기록의 안전한 처리는 유지한다.

## 상태별 동작

| 작성자 조치 | 새 목록·새 플레이 | 작성자 원본 | 이미 시작한 플레이 |
| --- | --- | --- | --- |
| 비공개 초안 저장 | 작성자만 접근 | 유지 | 해당 없음 |
| 공개 | 공개 목록 및 새 플레이 허용 | 유지 | 독립 실행 |
| 공개 해제 | 공개 목록·새 플레이에서 제외 | 유지 | 시작 시점 원본으로 계속 진행 |
| 공개 작품 수정 | 이후 새 플레이에 새 원본 적용 | 새 버전 원본 유지 | 시작 시점 원본으로 계속 진행 |
| 작성자 계정 삭제 | 새 공개 접근 차단이 원칙 | 원본·메타데이터 처리 필요 | 고정된 실행은 종료까지 보존 |

현재 실행 서비스는 시작할 때 작품 원본을 실행 저장소에 고정한다. 따라서 공개 해제·수정·프로세스 재시작 뒤에도 이미 시작한 실행은 원래 내용으로 이어진다. 다만 고정 저장 공간 한도에 도달하면 새 실행을 거절하며, 이미 고정된 실행을 임의로 바꾸지 않는다.

## 현재 코드에서 확인한 보호 경계

- 비공개 작품은 새 실행 시작을 거절한다.
- 공개 작품의 상세 목록에는 실행에 필요한 비공개 정답·미공개 장면 원본을 포함하지 않는다.
- 시작된 실행은 패키지 고정본을 사용하므로 작성자가 수정해도 진행 중 결말이 바뀌지 않는다.
- 초안 소유자 검증과 작성량 제한이 서버에 있으며, 작성 기능을 다시 열더라도 브라우저 권한만으로 우회할 수 없다.

## 운영 결정이 필요한 항목

1. **계정 삭제:** 작성자의 공개 작품을 즉시 비공개 처리할지, 일정 유예 뒤 삭제할지와 기존 URL 응답 방식을 결정한다.
2. **원본 삭제:** 진행 중 실행이 끝날 때까지 고정본을 보존할 기간과 저장 용량 한도를 결정한다.
3. **강제 조치:** 저작권·안전 신고로 작품을 숨길 때 새 플레이만 중단할지, 진행 중 플레이에도 중단 안내를 보낼지 결정한다.
4. **기록 보존:** 작품 원본 삭제 후에도 익명 집계·평점·후기를 유지할지와 이용자 안내 방식을 결정한다.

운영 결정을 적용하기 전에는 현재의 안전한 기본값, 즉 **새 시작은 중단하고 이미 시작한 실행은 고정본으로 끝까지 허용**을 유지한다.
