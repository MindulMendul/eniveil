# 분석·광고 동의 정책 감사

이 문서는 #177의 코드·문서 감사 결과다. GTM 및 GA4 관리자 콘솔의 실제 설정은 저장소 접근만으로 검증할 수 없으므로, 아래의 **운영 확인 필요** 항목은 별도로 확인해야 한다.

## 확정된 서비스 정책

| 선택 | GA 품질 분석 | 서버 게임 품질 분석·Faro | 로그인·플레이 | 광고·마케팅 |
| --- | --- | --- | --- | --- |
| 미선택/수집 안 함 | 차단 | 차단 | 제한 | 금지 |
| 기본 수집 | 허용 | 차단 | 제한 | 금지 |
| 전체 수집 | 허용 | 허용 | 허용 | 금지 |

- 목적은 게임 품질 개선, 난이도 분류, 개인 실력 지표이며 광고·마케팅·개인화에는 사용하지 않는다.
- 광고 저장, 광고 사용자 데이터, 광고 개인화는 Google consent에서 항상 `denied`로 유지한다.
- 페이지 URL의 쿼리·해시, 초대 코드, 계정 ID, 채팅 원문, 정답과 비공개 본문은 외부 분석 이벤트에 포함하지 않는다.
- 전체 동의는 30일, 익명 선택은 15분 동안만 유효하다. 축소·철회 시 해당 동의에 연결된 추가 분석 기록을 삭제하고 웹소켓·서비스 접근을 제한한다.

근거: `docs/collection-consent.md`, `docs/gtm-analytics.md`, `apps/server/src/modules/platform/consent.ts`, `apps/web/src/analytics.js`.

## 코드상 검증 결과

- 첫 방문 모달은 세 선택지를 명시하고, 모달 닫기·Esc를 동의로 취급하지 않는다.
- 동의 근거는 서버 HttpOnly 쿠키 및 SQLite 기록이며, localStorage는 탭 동기화에만 쓴다.
- GTM 컨테이너는 허용된 동의 범위에서만 초기화한다. QA는 전용 컨테이너가 없으면 비활성화한다.
- 서버 추가 분석 기록은 동의 토큰과 연결되며, 철회·축소·계정 삭제 경로에서 삭제된다.
- GA/Faro에 이미 전송한 데이터는 서버 DB 삭제와 별개이며 각 제공자의 보관·삭제 설정을 따른다.

## 운영 확인 필요

1. GTM 컨테이너에 GA4 외 광고·리마케팅·자동 클릭/폼/DOM 수집 태그가 없는지 확인한다.
2. GA4 Google 태그의 자동 `page_view`와 향상된 측정의 History 기반 페이지 조회를 끄고, 앱의 허용 목록 이벤트만 받도록 확인한다.
3. GTM Preview 및 GA4 DebugView에서 동의 전 요청 0건, 허용 후 SPA 이동당 `page_view` 1건인지 확인한다.
4. GA4/Faro의 보관·삭제 기간이 개인정보 처리방침의 고지와 맞는지 확인한다.
5. 컨테이너 변경 권한자와 게시 이력을 운영 기록으로 남긴다.

운영 콘솔 확인 전에는 “실제 외부 분석 설정까지 완료”로 표시하지 않는다.
