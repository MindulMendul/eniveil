# 작품 평점·후기 운영 정책

## 적용 기준

- 평점과 후기는 결말을 확인한 해당 플레이 참가자만 작성한다.
- 평점은 1~5점 또는 건너뛰기이며, 동일 참가자는 동일 플레이에서 한 번만 제출한다.
- 후기는 동일 플레이·작성자 조합에서 한 건만 유지하며 재제출하면 수정으로 처리한다.
- 스포일러 포함 여부는 작성자가 표시한다. 스포일러 후기는 목록과 API 기본 응답에서 본문을 제외하고, 이용자가 명시적으로 열 때만 본문을 제공한다.
- 평점 집계는 서버가 확인한 플레이 기록만 사용한다. 클라이언트가 보낸 작품 ID나 평점을 신뢰하지 않는다.

## 현재 구현과의 정합성

서버는 결말 완료 여부, 참가자 소유권, 평점 범위를 검증한다. 후기의 키는 세션과 작성자 조합이고 재제출은 본문·스포일러 값을 갱신한다. 목록은 스포일러 본문을 전달하지 않는다.

## 운영 조치 기준

후기 단위 신고와 동일 이용자의 중복 신고 방지는 제공한다. 신고 목록은 관리자 인증 API에서만 조회한다.

- 자동 필터와 영구 계정 제재는 도입하지 않는다.
- 신고가 접수되어도 검토 전에는 후기를 자동으로 숨기지 않는다. 긴급 사유도 이 단계에서는 예외로 두지 않는다.
- 숨김·삭제·복구·일시 제한의 운영 이력, 통지와 이의 제기 경로는 제재 기능을 배포하기 전에 추가한다.
