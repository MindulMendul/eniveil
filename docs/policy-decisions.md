# 운영 정책 결정 기록

## #179 창작물 권리와 서비스 이용 허락

- 창작물의 저작권은 창작자에게 남긴다.
- 창작자는 서비스 운영에 필요한 비독점적·전 세계적·무상 이용 허락(저장, 복제, 기술적 변환, 전송, 공개 표시, 서비스 홍보)을 부여한다.
- 허락은 작품이 공개된 동안 적용하며, 공개 해제·삭제 및 종료 후의 보존본·진행 중 플레이·법적 보관 범위는 별도 약관과 법률 검토로 확정한다.
- 제3자 소재를 올리는 창작자는 필요한 권리를 확보해야 한다. 서비스는 신고·권리 분쟁 절차를 별도 운영 정책으로 둔다.

## #180 신고 공개 상태

- 신고가 접수되어도 검토 전에는 작품·후기·계정을 자동으로 숨기지 않고 공개 상태를 유지한다.
- 처리 기한은 현재 정하지 않는다.
- 개인정보 노출·불법성 주장 등 긴급 사유도 현 단계에서는 자동 예외를 두지 않는다. 향후 AI 사전 분류 또는 운영 정책을 도입할 때 이 결정을 재검토한다.

## #182 플레이 기록과 제작자 통계

- 결말 뒤 정답 설명·해설은 작품의 `mstory` 원본에 포함해 해당 작품의 결과 화면에서만 제공한다.
- 제작자에게는 개인별 참가 기록, 역할, 선택, 정답, 채팅 원문, MMR을 제공하지 않는다.
- 제작자 통계는 작품·버전 단위의 익명 집계(완료율, 평균 시간, 이탈 단계, 평점)만 제공하며 표본이 5명 미만이면 표시하지 않는다.

## #184 운영 조치 범위

- 가능한 조치는 작품/후기 숨김 또는 삭제, 계정의 일시 제한으로 한정한다.
- 일시 제한의 최대 기간은 30일이다. 영구 계정 제한은 도입하지 않는다.
- 이의 제기 기한·담당자·통지 방식은 아직 결정되지 않아, 실제 제재 기능 배포 전 추가 결정이 필요하다.

## 외부 품질 측정

- Grafana Faro를 오류·세션·성능 측정에 계속 사용한다.
- Faro 수집기 운영 위치와 보관 기간은 추후 실제 운영 설정을 확인한 뒤 개인정보 안내에 확정한다.
