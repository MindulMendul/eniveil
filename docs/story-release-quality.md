# 플레이 작품 출시 품질 기준

이 문서는 #193의 출시 판단 기준이다. 작품 수·제작 일정·외부 권리 확보는 운영 승인 전에는 확정하지 않는다.

## 출시 후보의 최소 수용 기준

### 콘텐츠 정합성

- 시작 안내에서 인원, 예상 시간, 장르, 난이도와 스포일러 주의 범위를 확인할 수 있다.
- 모든 역할은 각자만 볼 수 있는 정보와, 결말에 이르는 최소 한 개 이상의 합리적 추론 경로를 가진다.
- 단서·아이템·자원·단계 전환·최종 선택을 처음부터 끝까지 검수하고, 정답과 모순되는 경로가 없는지 확인한다.
- 실패·시간 만료·중도 이탈·재접속에서도 결말 또는 안전한 종료 흐름으로 귀결된다.

### 제품 검증

- 방 생성, 공개/친구/비밀방 입장, 초대, 정원 경쟁, 재접속을 실제 서로 다른 세션으로 확인한다.
- 한국어와 영어의 버튼·오류 안내·모달을 확인하고, 360px 폭과 키보드만으로 핵심 흐름을 끝까지 수행한다.
- 역할 비밀·정답·비공개 원본은 다른 참가자와 공개 목록 API에 포함하지 않는다.
- 시작, 진행, 결말, 평점까지의 서버 권한·중복 요청·실패 롤백 테스트를 추가한다.

## 출시 순서 제안

1. 현재 4인 미공개 작품 가운데 하나를 정식 출시 후보로 고른다.
2. 원본 작성자와 서비스의 이용 범위, 수정 가능 여부, 크레딧 문구를 기록해 권리 확인을 끝낸다.
3. 내부 2회와 외부 비공개 테스트 1회를 거쳐 위 수용 기준의 결함을 수정한다.
4. 작품 메타데이터와 스포일러 경고를 검수한 뒤 공개한다.
5. 완료율·이탈 지점·평점은 개인 식별 정보 없이 집계해 다음 작품 보완에 사용한다.

## 첫 정식 다인 작품 기획 기준

| 항목 | 결정 |
| --- | --- |
| 인원 | 3명 |
| 목표 시간 | 60분 |
| 장르 | 미스터리 스릴러 |
| 플레이 구조 | 각 참가자는 시작부터 서로 다른 개인 목표를 가지며, 결과에서 목표 달성 점수를 함께 정산한다. |
| 제작 | 자체 제작, 담당: 민둘맨둘 |

점수 규칙은 개인 목표의 공개 시점, 팀 공통 목표와의 충돌, 동점 처리, 실패·중도 이탈 시 점수 처리를 시나리오 설계 단계에서 명시해야 한다. 역할 비밀과 목표·점수는 #182의 공개 정책에 따라 결과 화면 전까지 다른 참가자에게 노출하지 않는다.

- 외부 원고·이미지·음원 사용 시 권리 증빙 및 크레딧 방식
- 연령 등급과 민감 표현 기준 (#186)
- 창작물 이용 허락과 게시 후 조치 정책 (#179, #180)
