# 첫 방문 동의와 게임 품질 목적 수집

#173의 최종 사용자 결정: 전체 동의 후 로그인·플레이하며 수집 데이터는 게임 품질 개선, 난이도 분류와 개인 실력 지표에만 사용한다. 광고·마케팅에는 사용하지 않는다.

| 범위 | GA 품질 분석 | 서버 플레이 분석·Faro | 로그인·게임 |
| --- | --- | --- | --- |
| 미선택/수집 안 함 | 차단 | 차단 | 차단 |
| 기본 수집 | 설정된 GA만 | 차단 | 차단 |
| 전체 수집 | 설정된 GA | 허용 | 허용 |

서비스 소개·개인정보 안내, 동의 설정, 계정 확인·로그아웃·탈퇴는 전체 동의 없이 접근할 수 있다. 모달 닫기나 Esc는 동의가 아니며 서비스 제한이 유지된다. 기본 수집은 운영 필수 데이터라는 의미가 아니다.

## 동의의 저장·검증

- 버전2, 범위, 서버 시각, 현재 계정 식별자를 저장한다. 무작위 HttpOnly/SameSite=Lax 쿠키를 SHA256 해시로 조회한다. 운영에서는 Secure 쿠키다. localStorage는 다른 탭 알림일 뿐 허용의 근거가 아니다.
- 이 브라우저·계정에30일간 적용한다. 명시적으로 선택한 최초 익명 동의는 바로 이어지는 첫 로그인 계정에 연결한다. 이후 다른 계정·로그아웃·다른 기기에는 자동 이전하지 않는다. 기존 analytics-consent-v1은 새 전체 동의로 승격하지 않는다.
- POST 응답 후 GET으로 쿠키와 계정을 재확인한 뒤 활성화한다. 저장 실패·계정 변경·오래된 응답에서 허용을 추정하지 않는다. 다른 탭 변경은 BroadcastChannel/storage 알림과 서버 재확인으로 반영하고, 다시 보이는 탭·계정 변경·만료에서도 확인한다.
- HTTP 서비스 경계와 WebSocket 명령·snapshot 전송에서 전체 동의를 검증한다. 축소/철회 시 연결을 닫고 이후 명령을 거절한다. 클라이언트 버튼만 막는 구조가 아니다.

## 실제 수집 및 보관

현재 추가 수집 지점은 기존 솔로/창작 작품의 서버 생성 이벤트(작품·세션·행동 ID, 진행·결과·시간)와 story vitals다. collection_records가 동의와 이벤트/vital을 연결하며 로그인 시 계정에 연결된다. 별도의 원문 채팅 수집이나 공개 개인 데이터 API는 추가하지 않았다. 이벤트/vital 저장과 동의 연결은 같은 SQLite 트랜잭션이다.

추가 기록은30일 기준으로 주기적으로 정리한다. 동의를 갱신해도 오래된 기록의 보관 기간은 연장하지 않는다. 기본 전환·철회 및 계정 삭제 시 해당 동의의 추가 기록을 삭제한다. 진행 복구용 story_runs와 사용자가 제출한 평점은 운영 데이터로 분리해 보존한다. 분석 기록은 동의별10,000건·전체50,000건, 동의 항목은50,000개로 제한하며 한도에서는 추가 분석을 중단한다.

GA에는 허용한 품질 이벤트·속성만 전달하며 쿼리/해시, 사용자 계정 ID, 채팅·정답·비공개 본문은 보내지 않는다. 광고 이벤트는 전송하지 않고 Google 광고 저장/사용자 데이터/개인화는 denied로 고정한다. Faro도 전체 동의 전에 시작하지 않고 pending/철회 시 pause 및 전송 전 검사로 차단한다. 철회 후 외부 태그가 실행 중인 문서는 새로 열어 제거한다. 이미 GA·Faro에 전송된 기록은 각 시스템의 보관/삭제 설정을 따르며 서버 기록 삭제와 동일한 작업으로 보고하지 않는다.

## 별도 범위

#172의 난이도·MMR 산정과 본인 표시, 다인 채팅/전체 행동 수집은 이 모달 작업으로 완성됐다고 간주하지 않는다. 향후 수집 항목/목적을 넓힐 때는 버전과 안내를 갱신하고 다시 선택받는다. MMR의 공개 순위나 타인 데이터 표시는 포함하지 않는다.

GTM 콘솔의 실제 태그를 이 코드가 수정하거나 게시하지는 않는다. 운영자는 컨테이너의 태그가 게임 품질 전용 측정인지 확인하고 광고·마케팅/임의 커스텀 수집 태그를 사용하지 않아야 한다. Google 광고 consent denied만으로 임의 태그까지 통제할 수 있다고 간주하지 않는다. QA는 전용 컨테이너가 없으면 GA 태그가 비활성화되지만, 수집 범위 모달과 서버 서비스 제한은 유지한다.
