# Issue 126 — focus recovery follow-up

PR #138 이후 리뷰의 세 항목을 보완한다.

- 서버의 단계/스냅샷 업데이트 자체를 포커스 이동 조건으로 쓰지 않는다. 연결된 조작 요소의 포커스를 유지한다.
- 명시적인 경로·언어 이동은 본문으로 이동한다.
- 로딩이 끝난 뒤 실제 main이 준비되었을 때 로그인한 화면의 포커스를 복구한다. 임시 로딩 main에는 포커스를 보내지 않는다.
- solo 시작·소유권 전달·복귀 등 실제 DOM 화면 교체 또는 조작 요소 제거로 포커스를 잃은 경우 새 main으로 복구한다.
- 열린 dialog는 포커스를 유지하며 관찰자는 앱 종료 시 해제한다.

검증: 네트워크가 필요 없는 단위 테스트 5개/13 assertions와 전체 타입 검사·Astro 빌드를 로컬에서 통과했다. 타입 검사의 기존 미사용 CSS 경고 1건은 그대로다.

새 커밋의 실제 Chromium 상호작용 검증은 자동 승인 검토 서비스의 사용량 제한으로 실행하지 못했다. 실제 스크린리더 검증도 기존 #126과 동일하게 미완료다. 이 항목들을 통과라고 표시하지 않는다. 기존의 36화면 axe 및 키보드 결과는 #138 당시 결과이며 이번 변경의 브라우저 증거로 대체하지 않는다.

수동 재개 시 로그인 상태 새로고침, 진행 단계 변경 중 키보드 포커스 유지, 1인 시작/소유권/복귀, 경로·언어 이동, 모달 중 배경 갱신을 확인한다. 게임 비밀이나 토큰을 검증 로그로 수집하지 않는다.
