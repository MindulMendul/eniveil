# Issue 112

- 사용자 확인에 따라 친구 버튼은 계정 로그인 상태의 로비(방 진입 화면)에만 표시한다. 게스트/로그아웃·방/플레이·창작마당·계정 화면에는 플로팅 버튼이 없다.
- 네이티브 dialog의 오른쪽 패널에서 실제 요청·친구 API를 사용한다. 수락된 친구의 접속 WebSocket만 온라인으로 표현하고 온라인/오프라인을 위·아래로 구분한다. 패널이 열려 있는 동안 15초마다 조용히 갱신한다. 프로세스 밖 접속/별도 기기의 푸시 상태를 추측하지 않는다.
- 닫기·Escape·패널 바깥 클릭, 패널 내부 Tab 이동과 호출 버튼으로 포커스 복귀를 확인했다. 모바일에도 바깥 클릭 영역을 남기고 하단 여백으로 버튼이 마지막 콘텐츠를 가리지 않게 한다.
- 로그아웃·경로/계정 변경 시 패널을 파괴해 요청을 중단하고 목록을 제거한다. 401/403 응답도 데이터 제거·패널 닫기를 수행한다. 실패한 목록/검색 결과를 이전 성공 결과로 보이지 않도록 정리한다.
