# 공통 이미지 크기·용량 제한 검증

2026-11-08. 원본은10MiB 이하, 가로·세로 각각4,096px 이하이며 총1,600만 픽셀 이하, 변환 WebP는1MiB 이하로 제한한다. 경계값은 허용하고 초과하면 자동 축소 없이 거절한다. 브라우저 변환과 Sharp 빌드 모두 같은 shared 정책을 사용한다. 이미지 업로드 API는 아직 제공하지 않는다.

기본 `bash scripts/codex/verify.sh` exit0: 타입·빌드 및101 tests / 5,277 assertions 통과. 테스트는 경계값, 비정수/음수/비정상 치수, 길쭉한 이미지, 픽셀 예산, 원본 용량, 실제 무작위 픽셀 WebP 출력 초과, 현재 관리 자산의 크기·용량·디코딩을 포함한다.

Chromium155에서 외부 요청을 모두 차단하고 로컬 route로 공통 모듈만 제공하여 실제 브라우저 변환을 확인했다. 정상 PNG→WebP, 원본10MiB 초과, 폭4,097px, 높이4,097px, 4,096×4,096 픽셀 초과, 실제 무작위1024×1024 이미지의 WebP1MiB 초과 거절까지6개 검증이 통과했다. QA/운영 서버와 데이터에는 접근하지 않았다.

`--browser` 래퍼는 저장소의 `test:e2e` 부재로 exit1이다. 위 실제 Chromium 검증으로 보완했으며 래퍼 자체를 통과로 기록하지 않는다. UI 변경은 없다.
