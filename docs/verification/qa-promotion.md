# QA promotion review — 2026-11-08

PR #140의 승격 리뷰에서 다음을 수정했다.

- 접속 만료 60초 뒤에도 참가 이력은 보존한다. 투표 완료는 현재 방에 남아 있는 참가자의 투표로 판단하고, 만료 직후에도 완료 조건을 다시 평가한다. 빈 방의 세션은 endedAt을 기록해 종료하며, 결말에 도달하지 않은 종료는 완료 통계에 포함하지 않는다.
- 마이페이지 FriendsPanel의 401/403을 App까지 전달한다. 친구창과 공통 처리로 계정/스냅샷을 비우고 WebSocket·재접속 타이머·대기 중 요청을 정리한다.
- issue87의 두 브라우저 스크립트는 표시된 자체 loopback 서버에서만 실행한다. 브라우저 요청은 같은 origin으로 제한하고, 직접 API 호출도 redirect를 거부한다.

검증: 자체 메모리 DB 서버 127.0.0.1:3212, Chromium155. 기본 타입·빌드 단계 및 Bun 94 tests/5,173 assertions 통과. UI --browser wrapper는 test:e2e 부재로 exit1이며 통과로 표시하지 않는다. 별도 실제 브라우저에서 다음을 확인했다.

- 마이페이지에서 친구 목록 새로고침 응답을 401/403으로 바꾸고 계정 화면이 로그인 화면으로 돌아오는지 확인. 기존 WebSocket이 닫히고 2.2초 후에도 재접속/계정 화면 복구가 없는지 검사. 한국어/영어 × 1440/320px × 401/403 총8개 조합 통과.
- 기존 issue87/browser.cjs 전체 작품 플레이·편집/비공개 중 버전 고정·완료/평점·이동/뒤로 가기 검증 통과.
- empty-opening-browser.cjs 한글1440px/영어375px에서 빈 오프닝 후 조사 진입·재배치·pageerror0 통과.
- 두 스크립트 모두 QA URL과 표시되지 않은 loopback을 브라우저 실행 전에 거부하는 4개 조합 통과. QA에 테스트 데이터는 쓰지 않았다.

## 이번 승격에서 확장하지 않은 제안

- 친구 요청 발신 취소와 친구 삭제는 #111의 승인 범위인 검색/요청/수락/거절 외의 API·UI 기능 추가다. PR #140의 해당 리뷰 스레드에 범위 근거를 기록했다.
- 비활성 pinned play TTL은 재개 가능한 플레이의 유지 기한을 새로 정하는 정책이다. 현재 64MiB 저장 예산과 종료/중단 시 해제는 유지한다. 중단 요청을 보내지 못한 플레이가 쌓이면 새 시작이 429로 거절될 수 있는 기존 제약은 남아 있다. 이번 QA 승격에서 플레이 만료 시간을 임의 추가하지 않으며 별도 정책 결정이 필요하다. 이 변경은 그 기존 제약을 해결했다고 주장하지 않는다.
