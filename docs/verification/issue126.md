## 실행 근거

- 2026-11-08 기본 verify 83 tests/5,122 assertions 통과. --browser는 기존 test:e2e 부재로 기본 검사 후 exit 1. 이후 모달 키보드 순환·복귀를 실제 브라우저에서 추가 검증했다.
- 자체 메모리 DB 서버, 실제 Chromium, 한국어·영어 × 1440/320px: Tab→본문 건너뛰기, 중복 닉네임 오류·수정·값 보존, 마이페이지 이동 후 포커스, 실제 공개 작품 상세 모달의 Tab 순환·Escape·호출 버튼 복귀·버튼 제거 후 본문 복귀를 확인했다.
- 같은 조합에서 글자 200% 및 텍스트 간격 변경·320 CSS px 재배치·reduced-motion 조건의 가로 넘침 없음을 확인했다. 이는 OS/브라우저의 모든 확대 구현을 검증했다는 뜻은 아니다.
- 로그인·로비·창작마당·편집기·마이페이지·약관·개인정보·소개·404의 한·영 × 1440/320px 36화면: main/h1 각각1, main 중첩 없음, 목록의 직접 자식이 li임을 점검했다. axe-core WCAG2 A/AA·2.1 AA/best-practice 위반0건. 결과는 issue126/audit.json에 기록한다.
- 방/플레이·저장/로그아웃·탈퇴의 서버 회귀는 기존 검사로 유지한다. 게임 규칙·시간 제한을 변경하거나 다른 역할 비밀을 접근성 이름에 추가하지 않았다.

## 미검증 / 병합 차단

- 현재 Linux 실행 환경에 Orca·speech-dispatcher·AT-SPI가 없고 sudo/지원 패키지 설치기와 데스크톱 제어 도구도 제공되지 않았다. NVDA+Chrome 또는 VoiceOver+Safari 등 실제 스크린리더 조합은 실행하지 못했다.
- 실제 보조기기로 주요 전체 이용 흐름을 확인하기 전 WCAG 전체 적합성 또는 이 이슈의 모든 완료 조건 통과를 주장하지 않는다. 해당 검증과 남은 게임/창작 상호작용의 수동 점검이 끝날 때까지 이 PR은 draft로 유지한다. 운영 배포 없음.
